# 🌟 Modulación en JavaScript

## 🎯 Propósito
Este repositorio fue creado como parte de un **proyecto de estructuración de código** en JavaScript, aplicando el concepto de **modulación**. El objetivo principal es mejorar la organización del código dividiéndolo en módulos reutilizables.

El objetivo es explorar conceptos clave de desarrollo web utilizando:

- 🌐 **HTML**: Para estructurar el contenido.
- 🎨 **CSS**: Para aplicar estilos y mejorar la experiencia visual.
- ⚙️ **JavaScript (ES6 Modules)**: Para dividir la lógica en módulos independientes y reutilizables.

Este proyecto está diseñado para facilitar la comprensión de la modulación en JavaScript, promoviendo buenas prácticas en el desarrollo de software.

---

## 🚀 Cómo empezar

### 1. Clonar el repositorio
Para comenzar, clona este repositorio en tu máquina local usando el siguiente comando:

```bash
git clone https://github.com/luistalero/modulacion.git
```

### 2. Estructura del proyecto
El proyecto está organizado en las siguientes carpetas y archivos principales:

- **`index.html`**: Archivo principal donde se integra el código modularizado.
- **`styles/`**: Carpeta que contiene archivos CSS para el diseño de la página.
- **`modules/`**: Carpeta que almacena los módulos JavaScript utilizados en el proyecto.
- **`app.js`**: Archivo principal de JavaScript que importa y maneja los módulos.

---

## 🛠️ Tecnologías utilizadas

Este proyecto utiliza las siguientes tecnologías:

- 🌐 **HTML**: Define la estructura básica de la página.
- 🎨 **CSS**: Aplica estilos para mejorar la experiencia visual.
- ⚙️ **JavaScript (ES6 Modules)**: Permite dividir la funcionalidad en archivos modulares.
